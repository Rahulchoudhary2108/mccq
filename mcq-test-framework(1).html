Formatting guide — how to write questions

Separate each question with a blank line. Mark the correct option by putting * right after it. Option letters can be A., A), a. — any style works.

Which planet is known as the Red Planet?
A. Venus
B. Mars*
C. Jupiter
D. Saturn

2. What does HTML stand for?
A) Hyper Trainer Marking Language
B) Hyper Text Markup Language*
C) Hyper Text Marketing Language
D) None of these

No asterisk? Add a line like Answer: B or Ans: B at the end of the block instead — both work.

Prefer spreadsheets? A CSV with columns Question,OptionA,OptionB,OptionC,OptionD,Answer is also auto-detected on upload.

Setup guide — connect your leaderboard sheet (one-time, ~3 minutes)

Your leaderboard sheet is already set up: open it here. A plain sheet link can't accept writes from a webpage — Google requires a small script layer for that, which it hosts for free.

1. Open the sheet above. 2. In it, go to Extensions → Apps Script. 3. Delete the placeholder code and paste this in:

function doGet(e) {
  var sheet = getSheet_();
  var rows = sheet.getDataRange().getValues().slice(1);
  var data = rows.map(function(r){
    return { name: r[0], score: r[1], total: r[2], percent: r[3], date: r[4] };
  });
  data.sort(function(a,b){ return b.percent - a.percent; });
  return ContentService.createTextOutput(JSON.stringify(data.slice(0,50)))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  var body = JSON.parse(e.postData.contents);
  var sheet = getSheet_();
  sheet.appendRow([body.name, body.score, body.total, body.percent, new Date()]);
  return ContentService.createTextOutput(JSON.stringify({status:"ok"}))
    .setMimeType(ContentService.MimeType.JSON);
}

function getSheet_() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("Leaderboard");
  if (!sheet) {
    sheet = ss.insertSheet("Leaderboard");
    sheet.appendRow(["Name","Score","Total","Percent","Date"]);
  }
  return sheet;
}

4. Click Deploy → New deployment → Web app. Set "Execute as" to yourself and "Who has access" to Anyone. Deploy, then copy the web app URL — it ends in /exec.

5. Paste that URL above. Every submitted score becomes a row in a "Leaderboard" tab on your sheet — sort, filter, or chart it however you like, since it's just your own spreadsheet.
